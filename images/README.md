Você pode substituir qualquer imagem diretamente pelo GitHub.

### Como trocar uma foto

1. Abra este repositório no GitHub.
2. Entre na pasta `images`.
3. Clique em **Add file → Upload files**.
4. Envie a nova foto usando o nome correspondente.
5. Se o GitHub informar que o arquivo já existe, substitua o arquivo existente.
6. Faça o commit.

O site continuará usando automaticamente a imagem nova.

Não é necessário alterar o `index.html` para trocar as fotos.
